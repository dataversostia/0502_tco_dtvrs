# 0502_tco_dtvrs

Dashboard interactivo de la evolución del tipo de cambio oficial (Bs / $) desde el 5 de agosto de 2024, con referencia del mercado paralelo (TCM), USDT y bancos (BCB). Business case de [Dataversos](https://dataversos.com).

- Filtros por periodo, mes (selección múltiple) y rango de fechas.
- Gráficos de líneas, barras y dona, brecha con el paralelo y detalle diario exportable a CSV.
- Tema claro / oscuro / sistema y paleta de marca Dataversos.

`dashboard_tco_oficial_dtvrs.html` es un solo archivo autocontenido: se abre directamente en el navegador.
